กฎข้อที่ 2 🚫

Zero-Text Safeguard

AI ยังสะกดตัวอักษรไม่นิ่ง โดยเฉพาะภาษาไทย สั่งห้ามมีตัวหนังสือในภาพเด็ดขาด แล้วนำรูปมาพิมพ์ข้อความคมๆ ใน Canva

no text, no words, no letters

AI Prompt Bridge

ครูเพียงพิมพ์ไอเดียบทเรียนเป็นภาษาไทย แล้วคัดลอกคำสั่งโครงสร้างนี้ส่งให้ Gemini หรือ ChatGPT เพื่อให้ AI ออกแบบ Prompt ภาษาอังกฤษระดับมือโปรให้พร้อมนำไปป้อนใส่ Banana หรือเครื่องมือสร้างภาพทันที: 

คุณคือผู้เชี่ยวชาญด้านการออกแบบสื่อการสอนและ Prompt Engineer สำหรับ AI สร้างภาพ (Gemini Image / ChatGPT)
ฉันต้องการสร้างภาพประกอบบทเรียนเรื่อง: [ระบุหัวข้อ เช่น วงจรชีวิตกบ / รูปเรขาคณิตสามมิติ / การทดลองแรงดันอากาศ]

ช่วยแปลงเป็น Prompt ภาษาอังกฤษสำหรับนำไปสร้างภาพ โดยมีเงื่อนไขบังคับดังนี้:
1. สไตล์ภาพ: 2D flat vector illustration, clean lines, educational clipart style
2. พื้นหลัง: pure white background (พื้นหลังขาวสนิท ไร้เงาสะท้อน)
3. คำสั่งความปลอดภัย: บังคับใส่ "no text, no words, no letters, no watermark" ท้ายคำสั่งเสมอ
4. ส่งผลลัพธ์มา 2 รูปแบบ:
   - ตัวเลือก A (แบบเรียบง่ายสำหรับใบงาน A4 --ar 1:1)
   - ตัวเลือก B (แบบมีฉากจำลองครบวงจรสำหรับสไลด์ --ar 16:9)
