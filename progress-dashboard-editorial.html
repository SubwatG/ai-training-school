3 เสาหลักฐานคิด (Three Pillars)

ตกผลึกให้ครูสายไม่เชี่ยวชาญเทคโนโลยีเข้าใจง่าย จำได้แม่นยำ ไม่หลงทางกับศัพท์เทคนิค

01
Input & Context
เสาที่ 1 — รูปแบบคำสั่ง

คุยให้ถูกทาง (1 งาน = 1 แชท)

• Text vs Scan: AI กินข้อความดิบเป็นอาหาร ทำไมรูปสแกนเบลอๆ ถึงตอบมั่ว
• กฎล้างกระดาน: แยกแชทตามเรื่อง ไม่คุยทุกวิชาปนกันในห้องเดียว
• Web Prompt Hub: คัดลอกโครงสร้าง บทบาท-บริบท-ภารกิจ-รูปแบบ ไปต่อยอดได้ทันที

02
Tool Triad
เสาที่ 2 — การแบ่งบทบาท

วางงานให้ถูกตัว (Gemini ➔ Canva)

• Gemini: สมองระดมไอเดีย ร่างแผนสอน และออกข้อสอบ 4 ตัวเลือก
• NotebookLM: สมองอิงตำราเรียน สกัดเนื้อหาจาก PDF แม่นยำ 100% (Zero Hallucination)
• Canva: มือประกอบร่าง จัดเลย์เอาต์ อย่าสั่ง AI วาดข้อความภาษาไทยในรูป ให้เอาข้อความมาพิมพ์เอง

Safety & PDPA
เสาที่ 3 — การตรวจทาน & ความปลอดภัย

ทางลัดสมการ
LaTeX to Word/Canva

แก้จุดตายของครูสายคำนวณที่พิมพ์สูตรใน Word ช้ามาก แปลงสมการจาก Gemini ลงเอกสารและใบงานได้ใน 2 วินาที คมชัด ไม่แตก

// SHORTCUT CHEAT SHEET
  • ➔ Word Desktop: Alt + = แล้ววางโค้ด
  • ➔ Word Online: วางโค้ด ➔ แทรกสมการ
  • ➔ Canva: แอป Math (สมการ)
  • ➔ Google Docs: Add-on Auto-LaTeX
word-equation-shortcut.tex 
% ตัวอย่างสมการคำนวณทางฟิสิกส์/คณิตศาสตร์
x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}

% แรงโน้มถ่วงสากล (ม.3 วิทยาศาสตร์)
F = G \frac{m_1 m_2}{r^2}
💡 วิธีใช้ใน Word: กดแป้นพิมพ์ Alt + = ➔ วางโค้ดด้านบน ➔ กด Enter (จะแปลงเป็นสมการสวยงามทันที)
canva-math-vector.tex 
% สูตรสถิติการแจกแจงปกติ (Z-score) สำหรับวางใน Canva Math
Z = \frac{X - \mu}{\sigma}
🎨 วิธีใช้ใน Canva: เมนูด้านซ้าย ➔ แอป (Apps) ➔ ค้นหา "Math" (สมการ) ➔ วางโค้ด ➔ ได้สมการเวกเตอร์คมกริบ พื้นหลังโปร่งใส
