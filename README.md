# AI Training School Portal

พอร์ทัลกิจกรรมและคู่มือสำหรับการอบรมการประยุกต์ใช้ AI เพื่อการจัดการเรียนการสอน

เว็บนี้จัดเตรียมไว้สำหรับคุณครูและบุคลากรทางการศึกษาใช้เปิดทดลองจริงในวันอบรม โดยมี:

- แผนการอบรมและกิจกรรมแบบลงมือทำ
- คลัง Prompt ภาษาไทยกว่า 370 รายการ
- คู่มือ Gemini, Canvas, Canva และ NotebookLM
- ไฟล์ PDF และ CSV จำลองสำหรับฝึกปฏิบัติ
- สไลด์และคู่มือประกอบการอบรม

## เปิดใช้งาน

เปิดเว็บไซต์จาก GitHub Pages ของ repository นี้ หรือเปิด `index.html` ผ่านเว็บเซิร์ฟเวอร์แบบ static

## สำหรับผู้ดูแล

ไฟล์ที่เผยแพร่ใน repository นี้มาจากโฟลเดอร์ `site/` ของ source project และคัดเฉพาะเว็บสำหรับผู้เข้าอบรม ไม่รวมเอกสารภายใน, research, log และ backup

## ข้อควรระวังสำหรับผู้เข้าอบรม

อย่าอัปโหลดข้อมูลนักเรียน ข้อมูลส่วนบุคคล เอกสารลับ หรือข้อมูลราชการที่ยังไม่ได้รับอนุญาตเข้าสู่เครื่องมือ AI

เนื้อหาที่สร้างโดย AI ต้องอ่านตรวจทานกับต้นฉบับก่อนนำไปใช้จริง
