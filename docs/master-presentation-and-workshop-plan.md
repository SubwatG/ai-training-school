## 1. การปิดจุดบอดสำคัญ: ระบบ "Zero-Prep Starter Kit" (สำหรับครูที่ไม่ได้เตรียมไฟล์มา)

ในการอบรมครู หากกำหนดเงื่อนไขว่า *“ต้องนำไฟล์งานจริงมา”* จะเกิดจุดบอดทันทีหากครูบางท่านไม่ได้นำไฟล์มา หรือใช้คอมพิวเตอร์เครื่องใหม่/มือถือ เพื่อให้การอบรมลื่นไหล 100% จึงออกแบบ **3 ทางเลือกคู่ขนาน (3-Tier Entry Paths)** ให้ครูเลือกใช้ได้ทันที:

```
+---------------------------------------------------------------------------------------------------------+
|                                    3-TIER ENTRY PATHS (เลือกได้ตามความพร้อม)                              |
+------------------------------------+----------------------------------+---------------------------------+
|  [PATH A: มีไฟล์จริงมา]             |  [PATH B: มีแค่หัวข้อในใจ]        |  [PATH C: ไม่มีไฟล์/คิดไม่ออก]   |
|  - อัปโหลดไฟล์ Word/PDF/รูปถ่าย     |  - พิมพ์หัวข้อ เช่น "เศษส่วน ป.5",|  - สแกน QR Code หยิบ             |
|    ข้อสอบเก่า แผนการสอน หรือเกณฑ์   |    "ระบบสุริยะ ม.2", "วPA 2569"   |    "Preset Scenario Card"       |
|  - ให้ AI ปรับปรุงและต่อยอด        |  - ใช้สูตร ร-บ-ภ-ผ สร้างจากศูนย์ |    มีข้อมูลจำลองครบ 8 กลุ่มสาระ |
+------------------------------------+----------------------------------+---------------------------------+
```

### รายละเอียดกลไก Preset Scenario Cards บนเว็บ (`site/prompts.html`):
1. **คลังโจทย์สำเร็จรูป 8 กลุ่มสาระ x 3 ระดับชั้น (ประถม / ม.ต้น / ม.ปลาย)**: เตรียมข้อความจำลอง (Simulated Texts) เช่น แผนการสอนวิทยาศาสตร์สืบเสาะ, ข้อมูลประวัติศาสตร์อยุธยา, โจทย์คณิตศาสตร์เรื่องสถิติ, เอกสารเกณฑ์ ว.PA จำลอง
2. **ปุ่ม "คัดลอกโจทย์พร้อม Prompt ในคลิกเดียว"**: ครูที่ไม่พร้อม สามารถกดปุ่มเดียวบนเว็บ แล้วนำไปวางใน Gemini / Canva / NotebookLM ได้ทันที ไม่ต้องเสียเวลานั่งคิดหรือพิมพ์เนื้อหาตั้งต้น

## 4. โครงสร้างบูรณาการองค์ความรู้จากสไลด์หลัก (Pedagogical Integrations)

เราได้นำประเด็นสำคัญจากสไลด์ `ai-for-education-teachers-th-slide-deck.html` เข้ามาแทรกในเนื้อหาอย่างกลมกลืน:

1. **Prompting ที่เน้น Context & Pedagogical Goal (ไม่ใช่แค่คำสั่งสั้นๆ)**:
   - ใช้โมเดล **Context $\rightarrow$ Goal $\rightarrow$ Input $\rightarrow$ Criteria $\rightarrow$ Output $\rightarrow$ Verification**
   - เช่น แทนที่จะสั่ง *“ขอข้อสอบ 5 ข้อ”* $\rightarrow$ เปลี่ยนเป็น *“ระบุระดับชั้น, วัตถุประสงค์เชิงพฤติกรรม, ความเข้าใจผิดที่พบบ่อย (Misconception), และระดับความยากตาม Bloom's Taxonomy”*
2. **AI-Native Pedagogy & การสอนในยุคที่มี AI**:
   - **Socratic Tutor**: ออกแบบให้ AI ค่อยๆ ถามนำ ไม่เฉลยคำตอบในทันที เพื่อฝึกการคิดของผู้เรียน
   - **Critique the AI**: สั่งให้ AI สร้างเฉลยที่มีจุดผิดอย่างแนบเนียน 1 จุด แล้วให้นักเรียนแข่งกันเป็นนักสืบตรวจจับจุดผิด
   - **Assessment Redesign**: ปรับวิธีวัดผลจากการส่งรายงานข้อความ มาเป็นการวัดกระบวนการคิด (Process-based) และการสะท้อนคิด (Reflection)
3. **Verification Ladder (บันไดตรวจทาน 3 ขั้น)**:
   - **ขั้นที่ 1 (ตรวจตาเปล่า - Red Flag Scan)**: ตัวสะกดภาษาไทยในภาพ, ตัวเลขแปลกๆ (เช่น 31 ก.พ.), วันที่ย้อนแย้ง
   - **ขั้นที่ 2 (Cross-check อ้างอิง)**: ถามย้อนกลับหาเลขหนังสือราชการ/ปี พ.ร.บ. แล้วค้นกูเกิลเช็ค
   - **ขั้นที่ 3 (Human Sign-off)**: ครูตรวจสอบความสอดคล้องกับหลักสูตรแกนกลางก่อนนำไปแจกนักเรียน
